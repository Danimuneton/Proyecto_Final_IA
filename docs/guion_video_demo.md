# Guion del video de demostración (3–4 minutos, plan B)

| Tiempo | Qué mostrar | Qué decir |
|---|---|---|
| 0:00–0:20 | Portada del README | Problema: la gente no entiende el PM2.5 del día. Datos reales del SIATA 2023–2024. |
| 0:20–0:50 | Pestaña **Mapa** con fecha 2024-03-15 | Color ICA por estación (Res. 2254/2017) y ranking. Cambiar la fecha a 2024-06-15 para mostrar la diferencia con la temporada crítica. |
| 0:50–1:30 | Pestaña **Serie de tiempo** (MED-BEME, 180 días) | Bandas ICA, norma 37 y guía OMS 15. El color de los puntos es el estado del HMM propio (Normal/Alerta/Episodio crítico); en marzo domina Episodio crítico. |
| 1:30–2:10 | Pestaña **Predicción** | Probabilidades de mañana, factores y persistencia. Cambiar a escenario "Personalizada" o marcar "domingo/festivo" y ver cómo cambia. Mostrar el backtesting. |
| 2:10–2:40 | Pestaña **Modelo y evaluación** | Tabla contra líneas base: mejora probabilística significativa, mejora pequeña y no significativa frente a persistencia. Matriz de transición del HMM. |
| 2:40–3:40 | Pestaña **Chat** | 1) "¿Puedo salir a trotar mañana? Tengo asma." → abrir "Herramientas usadas" (predict_tomorrow + search_docs) y "Fuentes". 2) "¿Cómo está el aire en Rionegro?" → manejo del error. 3) "¿Qué medidas contempla el POECA?" → citas. |
| 3:40–4:00 | README / limitaciones | Un año de datos, no es pronóstico oficial ni consejo médico, declaración de uso de IA. |
